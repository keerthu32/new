Industrial Battery Digital Twin

From visual mockup to behavior-driven twin with live telemetry mapping.

What changed

  • 3D circuit model built with Three.js
  • 500ms update loop for real-time-like telemetry
  • Battery + risk mapping and trend chart

How to run

Render this template from Flask and expose /api/twin/state.

If the endpoint is unavailable, a built-in fallback simulator keeps the twin moving.
